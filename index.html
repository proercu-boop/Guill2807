📐 Guía de Fórmulas ZKW: Definiciones exactas para auditorías y revisiones de dirección.
UPH — Units Per Hour
Capacidad de la operación
# Capacidad total de la línea
UPH = (Paquetes / Horas)
     × Operadores

# Equivalente:
UPH = UPPH × Headcount

# Ejemplo 2025-Ene:
13,627/10,568 × 50
= 64.47 pkg/hora
UPPH — Per Person Per Hour
Eficiencia de mano de obra
# Eficiencia individual
UPPH = Paquetes
       / Horas_totales_equipo

# horas = Σ hrs de todas
# las personas del turno

# Ejemplo 2025-S2:
4,158 / 2,195.32
= 1.8940 pkg/man-hr
UPP — Units Per Person
Target por operador
# Planeación de headcount
UPP = Paquetes
      / Num_Operadores

# Sin normalizar por tiempo
# Usar UPPH para comparar
# períodos distintos

# Ejemplo 2026-Ene:
13,983 / 39
= 358.5 pkg/persona
⚠ Estimación de Horas — Semanas 22 a 35
Aplica solo a 2026 · S22–S35 (Jun–Ago)
14 semanas estimadas
# A partir de S22 no se contaba con las Horas
# trabajadas (col K). Sí se tenían Paquetes (col L)
# y Operadores (col M) de la pestaña "UPH 2026".

Horas_est = Operadores × 51.98

# 51.98 = MEDIANA de (Horas / Operador) de las
# semanas 2–21 (reales), excluyendo la semana 1
# por ser arranque de año incompleto (9.4 h/op).

# Con Horas_est se calculan UPPH, UPH y UPP igual
# que las semanas reales. Estos valores son
# PROYECCIÓN, no medición directa.

# Validación:
UPPH real (S1–21)  = 1.611
UPPH est. (S22–35) = 1.763  (+9.5%)
# Diferencia moderada → factor razonable.
