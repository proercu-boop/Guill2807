[ Supermarket Sub KPI ] — Fill Rate por Fase

Definiciones — Fórmulas y Criterios KPI
// WAREHOUSE SUB KPI
Pending Trailer Qty        = Trailers acumulados sin procesar (target = 0)
Incoming Plan Accuracy (%) = Trailers llegados en plan / Trailers programados
Trailer sin Factura (%)    = Trailers sin factura / Total trailers (target = 0%)
Classifiers (GR)           = Facturas sin Goods Receipt acumulado (target = 0)
9010 H/Unit Avg            = Unidades promedio procesadas/hora en área 9010
Demurrage Cost (€)         = Costo por permanencia excesiva de trailer en planta

WH Accuracy Phase X (%)   = 1 - (Errores inventario / Total ubicaciones)
WH Downtime Phase X (%)   = Horas paradas WH razón interna / Horas totales turno
Sub Total (Accuracy)       = Promedio ponderado Phase 1 + 2 + 3
Sub Total (Downtime)       = Promedio ponderado Phase 1 + 2 + 3
// SUPERMARKET SUB KPI
Fill Rate Phase X (%)      = Piezas entregadas a tiempo / Piezas requeridas línea
Sub Total Fill Rate        = (Ph1 + Ph2 + Ph3) / 3

SM Accuracy Phase X (%)   = 1 - (Errores SM / Total ubicaciones SM)
SM Downtime Phase X (%)   = Horas paradas SM / Horas totales turno
Sub Total (Acc / DT)       = Promedio ponderado de las 3 fases
// EMBARQUES KPI
OTD (On Time Delivery) %   = Embarques a tiempo / Total embarques planificados
6S Performance (%)         = Score auditoría 6S por fase (orden/limpieza/std)
Accuracy Emb Phase X (%)   = Embarques sin error / Total embarques Phase X
Downtime Emb Phase X (%)   = Horas paro área emb / Horas totales turno emb

// B/C OPERATION EFFICIENCY
WH B/C HC                  = Operadores B/C activos en almacén vs plan MX
SM B/C HC                  = Operadores B/C activos en supermercado vs plan MX
Over Time (Hr)             = Horas extras acumuladas en el período

// MATERIAL LOST
Lost Amount (€)            = Valor de material no localizado en el período
Recover Amount (€)         = Valor recuperado del material extraviado
Final Lost (€)             = Lost Amount - Recover Amount (neto)
Recover Rate (%)           = Recover Amount / Lost Amount × 100
